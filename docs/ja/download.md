## 「100% ローカル完結・外部通信ゼロ」をご自身で検証する3つのステップ

機密性の高いソースコードや社内ドキュメントを扱うデスクトップエージェントとして、セキュリティ部門やエンジニアの皆様が抱く「外部へデータが送信されないか」という懸念に対し、以下の**物理的検証手順**を公開しています。

### Step 1：SHA-256 ハッシュの照合
ダウンロード後、PowerShell で以下のコマンドを実行し、上表の `SHA-256` と一致することを確認してください：
```powershell
Get-FileHash .\HYN-Agent-Setup-1.0.0.exe -Algorithm SHA256
```

### Step 2：LANケーブル抜線 / ファイアウォール遮断での完全オフライン稼働テスト
1. PC上で `Ollama`（`127.0.0.1:11434`）を起動します（または社内LANの vLLM / OneAPI エンドポイントを用意します）。
2. **Wi-Fi をオフにするか LAN ケーブルを抜いた状態**（あるいは Windows Defender ファイアウォールで外部インターネット通信を完全遮断し `127.0.0.1` のみ許可した状態）にします。
3. HYN Agent のモデル設定で **「Ollama（ローカルオフライン）」** を選択すると、外部ネットワーク一切なしでコード解析・リファクタリング・単体テスト実行・Office文書生成＆編集がすべて完結することを確認できます。

### Step 3：ローカル保存データと自動マスク済みログの監査
- 会話履歴、2層メモリ（Markdown形式）、ファイル変更スナップショットはすべてユーザー指定のローカルディレクトリ（`.hyn_agent/`）に平文構造で保存されます。
- `.hyn_agent/logs/main.log` および `renderer.log` では、書込前のサニタイズフック（`sanitizeLogMessage`）により `sk-*` や `Bearer`、`api_key` 等のトークン文字列が `***` に自動消去されていることを確認できます。

# ブラウザ対話型デモ（インストール不要）

> [!TIP] `.exe` のインストール不要・ブラウザ上でそのまま操作体験
> 企業のセキュリティ規定により外部ソフトの実行が制限されている採用ご担当者様・面接官の方のために、**HYN Agent デスクトップ版の「石瀾（Stone）」UI を 1:1 で再現した対話型サンドボックス**を用意しました。上部の **3つのシナリオタブ** の切り替え、ツール呼び出しカードの展開、下部の **4段階リアルタイム権限モード**、**コンテキストバジェット円環**、右ペインでの **シャドウGitチェックポイント Diff 比較** や **「✨ AI修正」インプレース更新** を実際にクリックして操作いただけます。

## 搭載されている3つの実演シナリオ

| シナリオ | 対応するバックエンド・フロントエンド設計 | クリックして操作できるUI要素 |
| :--- | :--- | :--- |
| **1. オフライン長時間実行＆シャドウGitチェックポイント** | `TurnHub` 単調増加 `seq`、`StuckDetector` L2 ループ防止、`git_checkpoints.py` 非侵襲スナップショット | ツールカード（`apply_patch` / `run_powershell`）の開閉、右ペインでのチェックポイント `#1 / #2` Diff 切替、下部 **「⚡ 完全自動」** 権限メニューの切替 |
| **2. Office高精細プレビュー＆選択範囲「✨ AI修正」** | `PreviewWorkbench.js`、`WpsFormatToolbar.js`、`AiSelectionPopover.js`、`patch_file_selection` | 右ペインのPPTスライド選択枠または **「✨ AI修正 (Ctrl+L)」** ボタンをクリックし、SSE によるインプレース更新と緑ハイライトを確認 |
| **3. Git Worktree マルチエージェント並列開発** | `team_runtime.py` 常駐メイト、`.hyn_wt/*` 分離ワークツリー、計画承認前の読取専用ゲート | `mate-frontend` カード内の **「🛡️ メイトの計画を承認」** ボタンをクリックし、書込ロック解除の遷移を確認 |

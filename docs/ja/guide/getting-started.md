# クイックスタート・導入手順

Helm は **Electron 44 + Vue 3.5 フロントエンド + 同梱 Python 3.13 FastAPI ローカルバックエンド** を一体化したデスクトップアプリです。追加の環境構築は一切不要で、`git`・`node`・`uvx` が未導入の企業貸与PCでも **System Doctor** が管理者権限なしでポータブル環境を自動構築します。

## 2. 最初のタスクを実行する3ステップ

```mermaid
flowchart LR
  S1["1. モデル設定 (Ollamaオフライン / 社内LAN / クラウドAPI)"] --> S2["2. ワークスペース指定 (Gitリポジトリや業務文書フォルダ)"]
  S2 --> S3["3. 5段階権限モード選択＆実行 (右ペイン即時プレビュー)"]
```

### Step 1：モデルプロバイダーの選択（100% オフライン対応）
左サイドバー下部の **「設定 (Settings) → モデル (Models)」** を開きます：
- **完全オフライン・機密環境の場合**：標準搭載の **「Ollama（ローカルオフライン）」** または **「社内LANモデル（企業内ネットワーク）」** を有効化します（APIキー不要）。
- **クラウドモデル利用時**：DeepSeek、Qwen、GLM、Kimi、Claude、Gemini、OpenAI 等に対応。APIキーは OS レベルの DPAPI で暗号化され、ログ出力前に自動マスクされます。

### Step 2：ローカルワークスペース（Workspace）の紐付け
左上の **「Helm」** ロゴ下のパスをクリックし、対象のリポジトリまたは文書フォルダを選択します。Git リポジトリでは `HEAD` や `git status` を一切汚さない **シャドウGitチェックポイント** が自動稼働します。

### Step 3：5段階の権限モード（Permission Mode）の選択
下部入力バー右側の権限ボタンから、キャッシュを壊さず実行中でも即座に切り替えられます：

| 権限モード | 推奨シーン | 動作仕様 |
| :--- | :--- | :--- |
| **`plan`（読取・計画）** | 大規模コード調査・事前設計レビュー | 読取専用ツールのみ許可し書込・コマンドを物理遮断。`PlanCard` で承認後に実装開始 |
| **`ask_all`（全件確認）** | 機密コード監査・本番設定調査 | 読取専用は自動許可。ファイル書込・コマンド実行はすべて事前確認 |
| **`default`（標準推奨）** | 日常の開発・オフィス文書作成 | 通常の編集確認と安全な読取コマンドを許可し、破壊的コマンドのみ確認を要求 |
| **`auto_edit`（自動編集）** | 高速な開発反復・文書ブラッシュアップ | ワークスペース内の編集（5世代バックアップ付）と読取コマンドを自動許可 |
| **`full_auto`（完全自動）** | **数時間の無人改修・チーム並列実行** | ワークスペース内の操作・MCP・チーム協働を自動承認（**保護パス `.git/hooks`・`.env*` 等は強制人間承認を維持**） |

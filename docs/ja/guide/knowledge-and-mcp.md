# ローカル知識ベースと MCP / Skills 拡張

## 1. ローカル知識ベース連携（RAGFlow + 根拠チェーン）

左サイドバーの **「ナレッジベース (Knowledge)」** から、ローカルまたは社内LANで稼働する **RAGFlow** に接続できます：
- **データセット＆文書管理**：社内規約・設計書・API仕様書をアップロードし、チャンク解析状態（`RUNNING` / `DONE`）を画面上で管理できます。
- **出典付きエビデンス構造化（`app/services/knowledge/evidence.py`）**：検索された文書チャンクはファイル名・スコア付きのエビデンスとして構造化注入され、ハルシネーション（事実無根の回答）を抑止します。

## 2. MCP（Model Context Protocol）サーバーの動的マウント

**「カスタマイズ (Customize) → MCP」** にて、任意の MCP サーバーを接続できます：
- **オンデマンド遅延起動**：アプリ起動時の速度低下を防ぐため、有効化された MCP サーバーは実際のツール呼び出し時に初めて起動され、終了時に安全にクリーンアップされます（`app/main.py`）。
- **サーバー別ポリシー制御**：サーバーごとに `allow` / `confirm` / `deny` を設定でき、セッションの4段階権限モードと連動します。

## 3. Skills・Hooks・Cron スケジュール自動化

- **Skills（スキルパッケージ）**：フレームワーク規約やドキュメント作成ガイドラインを登録し、必要な時だけ `load_skill` でコンテキストに読み込みます。
- **Lifecycle Hooks**：ツール実行前後（`PreToolUse` / `PostToolUse`）に権限チェックや監査フックを挿入できます。
- **Cron 自動化（Automations）**：指定したスケジュール（Cron式）で定期テストやレポート生成（`.docx` / `.pptx`）を無人実行します。

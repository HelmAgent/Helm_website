## 如何亲手验证「100% 本地离线、数据零出网」？

作为一款能够读写本地源码与企业内部文档的桌面端 Agent，我们理解开发者与企业安全部门对“闭源软件是否会偷偷上传数据”的审慎态度。你可以通过以下 **3 步物理级验证** 彻底确认 HYN Agent 的离线安全性：

### 第一步：校验安装包哈希与进程签名
1. 下载完成后，在 PowerShell 中执行以下命令比对 `SHA-256`，确保文件未经任何第三方篡改：
   ```powershell
   Get-FileHash .\HYN-Agent-Setup-1.0.0.exe -Algorithm SHA256
   ```
2. 客户端内置的 Python 运行时采用官方嵌入式分发包，前端渲染进程仅通过回环地址 `http://127.0.0.1:8001` 与本机 FastAPI 子进程通信。

### 第二步：物理断网或配置防火墙出站阻断运行
1. 在本机启动 `Ollama`（默认监听 `127.0.0.1:11434`）并拉取任一编码模型（如 `ollama pull qwen2.5-coder:14b`）。
2. **直接拔掉网线 / 关闭 Wi-Fi**（或在 Windows 高级安全防火墙中将 `HYN Agent` 设置为“禁止所有外部公网 IP 出站连接，仅允许 `127.0.0.1` 与企业局域网段”）。
3. 在软件设置页选择 **「Ollama（本机离线）」**，即可在 100% 物理断网状态下流畅执行代码重构、运行单元测试、生成并编辑 Office 文档。

### 第三步：审阅本地透明存储目录与脱敏日志
- 所有会话记录、双层记忆（`.md` 文件）、文件历史快照与运行日志均以明文结构保存在你指定的本地数据目录（默认位于安装目录同级的 `.hyn_agent/`，可在设置页随时迁移路径）。
- 打开 `.hyn_agent/logs/main.log` 与 `renderer.log`，你可以直接验证 Electron 主进程的 `sanitizeLogMessage` 钩子：任何形如 `sk-*`、`Bearer *`、`api_key` 的敏感凭据在落盘前均已被强制擦除为 `***`。

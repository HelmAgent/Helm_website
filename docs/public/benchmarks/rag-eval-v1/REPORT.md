## 2. 各阶段架构演进与消融增益归因

1. **`v0_baseline`（传统流式 PDF + 固定窗口机械切分 + 纯稠密向量 `vector_weight=0.95`）**：
   - 跨页表格（表 1-1 国产 NPU 续表）表头丢失、双栏文字交错；DOCX 故障机理长段落将章节标题与末尾【应急恢复步骤】切开；纯向量对相似错误码尾号（`ERR_HYN_4029` vs `4092`）区分度低，且混入 `OpenSandbox` 社区版干扰数据。
2. **`v1_mineru`（+ 版面感知 PDF 双栏与跨页表格重构）**：
   - 通过几何坐标分栏与跨页表头自动继承，将 **3_复杂表格与公式** 的事实召回率直接拉升至 **100.0%**。
3. **`v2_chunking`（+ AST/目录树父子层级面包屑注入 `[文档 > 章 > 节]`）**：
   - 为每个 DOCX/MD 语义切片自动注入完整章节路径，彻底解决标题与恢复命令远距离分离导致的指代丢失，将 **4_深层目录与跨段指代** 召回率提升至 **100.0%**。
4. **`v3_hybrid_rerank`（+ BM25 精确符号混合检索 + Cross-Encoder 时序权威重排 + 拒答阈值校准 `0.38`）**：
   - 结合精确符号匹配与版本效力重排（识别 `2026Q3 v2.1` 废止通知与 `2025 v1.0` 继承条款、压制 `OpenSandbox` 社区版干扰项），实现 **精确符号 100% 召回、干扰污染率降至 0.0%、超纲无答案题 100.0% 阈值拒识拦截**。

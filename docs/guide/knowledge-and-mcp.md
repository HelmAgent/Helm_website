# 本地知识库与 MCP / Skills 扩展

HYN Agent 不仅能直接读写当前工作区文件，还具备完善的知识检索（RAG）与插件化扩展体系。

## 1. 连接本地知识库（RAGFlow 证据链集成）

在左侧导航栏点击 **「知识库 (Knowledge)」**：
- **私有化 RAGFlow 对接**：填入本机或企业内网部署的 RAGFlow 服务地址（如 `http://127.0.0.1:9380`）与 API Key，点击测试连接。
- **数据集管理与文档解析**：支持在客户端内直接创建数据集、上传企业技术规范 / API 手册 / 历史架构文档，并实时监控文档切片解析状态（`RUNNING` / `DONE`）。
- **带溯源的证据打包（`app/services/knowledge/evidence.py`）**：当你在对话中挂载知识库后，Agent 检索到的文档切片会被自动结构化封装为带来源文件名与匹配得分的证据块，杜绝模型胡编乱造内部规范。

## 2. MCP（Model Context Protocol）服务器挂载

在 **「定制 (Customize) → MCP」** 面板中，你可以动态接入任意符合标准 MCP 协议的本地或内网工具服务器：
- **按需懒加载**：为加快客户端启动速度，后端启动时不会盲目拉起所有 MCP 子进程（见 `app/main.py` `_lifespan`），仅在启用并实际调用时按需连接，退出时统一安全回收。
- **独立权限策略**：每个 MCP Server 均可单独配置 `allow`（自动放行）、`confirm`（每次调用前询问）或 `deny`（禁用），并与会话级 4 档权限模式联动。

## 3. Skills 技能包与 Lifecycle Hooks

- **Skills（技能指令包）**：在 **「定制 → Skills」** 中管理可复用的领域技能（如特定框架代码规范、PPT 排版审美指南、安全审计清单）。Agent 可通过 `load_skill` 按需加载对应技能的详细指令，避免无关规则长期侵占上下文窗口。
- **Hooks（生命周期钩子）**：支持在工具执行前（`PreToolUse`）与执行后（`PostToolUse`）挂载自定义检查逻辑（例如权限门禁、代码格式化或安全审计钩子）。

## 4. Cron 定时无人值守任务（Automations）

在左侧导航栏点击 **「自动化 (Automations)」**：
- 支持通过标准 Cron 表达式配置周期性或定时触发的 Agent 任务（如：每天凌晨自动拉取最新测试分支、运行回归测试并生成 `.docx` 巡检报告）。
- 定时任务与权限引擎深度联动：非交互轮次默认拒绝高危操作，除非该定时任务会话被显式授权为 `full_auto` 模式。

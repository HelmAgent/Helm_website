# 快速开始与安装指南

Helm 采用 **Electron 44 + Vue 3.5 前端 + 内嵌 Python 3.13 FastAPI 本地后端** 架构，安装完成后即可直接运行，无需手动安装 Python 或配置外部数据库；若宿主机缺失 `git`、`node` 或 `uvx`，内置 **System Doctor** 支持免管理员权限一键拉取便携版工具链自愈。

## 2. 三步完成首次自治任务

```mermaid
flowchart LR
  S1["1. 配置模型源 (本机 Ollama / 企业内网 / 云端直连)"] --> S2["2. 绑定本地工作区 (Git 代码仓库或办公文档目录)"]
  S2 --> S3["3. 选择 5 档权限模式并启动 (右侧双模工作台实时预览)"]
```

### 第一步：配置大模型（支持 100% 物理断网）
打开左侧栏底部的 **「设置 (Settings) → 模型 (Models)」**：
- **极度隐私或无网环境**：直接开启内置的 **「Ollama（本机离线）」** 或 **「局域网大模型（企业内网）」**，无需填写 API Key 即可一键探测连通性。
- **高性价比与前沿云端模型**：内置 `8` 大供应商（DeepSeek、Qwen、GLM、Kimi、Anthropic Claude、Google Gemini、OpenAI 等），API Key 经系统级 DPAPI 加密入库，写日志前自动擦除脱敏。

### 第二步：绑定本地工作区（Workspace）
点击左侧栏顶部的 **「Helm」** 标识下方的工作区路径，选择你要处理的本地 Git 代码仓库或办公文档目录。
- 当工作区为 Git 仓库时，默认开启 **无侵入影子 Git 检查点（Shadow Git Checkpoints）**，将每步快照写入私有引用 `refs/hyn/checkpoints/<session_id>`，绝不污染你的当前分支与 `git status`。

### 第三步：选择 5 档会话权限模式并开始执行
在底部输入栏右侧点击 **权限模式按钮**，可在 **5 档交互模式** 间随时无感切换（零前缀缓存破环，下一次工具调用立即生效）：

| 权限档位 | 适用场景 | 行为特征 |
| :--- | :--- | :--- |
| **`plan`（只读规划）** | 陌生大库架构梳理、先审方案再动工 | 放行只读探查工具，物理拦截一切写文件与命令执行；生成交互式 `PlanCard` 待批准后开工 |
| **`ask_all`（步步确认）** | 高敏代码审计、生产配置排查 | 所有只读工具直接放行；任何写文件、打补丁或执行终端命令均弹出审批卡 |
| **`default`（智能默认）** | 日常推荐均衡模式 | 常规读写与安全只读命令放行，对潜在破坏性命令要求人工确认 |
| **`auto_edit`（自动编辑）** | 高频交互式编码与文档精修 | 工作区内写文件（自动留存 5 代快照）与白名单只读命令自动放行，其余命令需确认 |
| **`full_auto`（完全自治）** | **数小时长程重构与多代理并行** | 自动批准工作区内工具、MCP 与常驻团队协同；**敏感受保护路径（`.git/hooks`、`.env*`）与越界指令依然强制人工审批** |

## 3. 界面语言实时切换（中 / 日 / 英）
在 **「设置 → 外观 / 通用」** 中可随时切换 **简体中文 (`zh-CN`)**、**日本語 (`ja-JP`)** 与 **English (`en-US`)**，全界面与工具状态卡即时响应式重绘，无需重启窗口。
